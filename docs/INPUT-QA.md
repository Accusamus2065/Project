# 检查与验证

## 自动检查

在项目根目录运行：

```sh
python3 -m unittest discover -s tests -v
node --check harvest/web/app.js
```

前端回归脚本位于 `tests/test_*.cjs`，逐个使用 `node 文件路径` 运行。Node.js 仅用于验证。

测试覆盖权限、计件金额与价格快照、工时和数量边界、工序关联、成品核对、直售、月度报表、分页筛选、并发修正，以及请求失败和草稿保留。

## 界面检查

- 员工：添加计件和计时工作、重复产品过滤、总工时、提交与修正。
- 点货员：零数量、修改点货、报数变化后的复点确认。
- 经理：新建与引用工序、单位和单价联动、停用、核对详情、月度导出、操作记录筛选。
- 下拉菜单：键盘选择、关闭和焦点、必填提示；切换已有工序后栏宽和高度保持一致。
- 手机：320px、390px、430px 等窄屏下的长名称、菜单、弹窗和表格滚动。

界面测试使用演示或独立测试数据库，避免写入正式业务数据。正式上线前还需在实际 iPhone Safari 和 Android Chrome 验证软键盘、日期控件、屏幕旋转和网络中断，并执行备份恢复验证。
